01

INTRODUCE

현재는 Cloud Native Infrastructure와 DevOps에 관심을 두고, Kubernetes 기반 서비스 운영과 CI/CD, IaC, Observability를 중심으로 경험을 넓히고 있습니다.

시작은 지금과 꽤 다른 사회복지 분야였습니다. 사람과 환경, 그리고 서비스가 실제 사용자의 삶에 어떤 영향을 주는지에 관심을 가졌고, 이후 원래 관심있던 미디어 제작으로 옮겨가며 VFX 분야에 들어오게 되었습니다.

VFX 현장에서는 결과물을 만드는 일만큼이나 그 결과물이 만들어지는 환경과 시스템에 더 큰 흥미를 느꼈습니다. Houdini, Nuke, Maya 같은 제작 도구와 Render Farm, Linux 환경을 다루면서 작업자의 반복 작업을 줄이고, Pipeline 문제를 해결하고, 제작 환경을 안정적으로 유지하는 일을 경험했습니다.

그렇게 관심사는 Pipeline Automation → IT Infrastructure → Cloud / DevOps로 확장되었습니다. 분야는 바뀌었지만, 사용자가 더 안정적으로 일할 수 있는 환경을 만들고 반복적인 일은 자동화로 개선한다는 방향은 계속 이어지고 있습니다.

반복 가능하고, 관찰 가능하며, 운영할 수 있는 시스템을 만드는 엔지니어를 지향합니다.
