01

프로젝트 개요

일회성 실습 VM이 아니라 실제 사용하는 서비스를 계속 운영하면서 변경과 장애를 직접 경험하기 위한 개인 인프라다.

Raspberry Pi 기반 Linux 서버에서 Wiki.js와 개인 웹 서비스를 운영한다. Docker Compose로 서비스를 분리하고 Cloudflare Tunnel과 DNS로 외부 접근을 연결했다. 정적 웹 서비스는 GitHub Actions와 Self-hosted Runner를 이용해 배포하고, Wiki 데이터는 PostgreSQL과 SQL Dump 백업으로 관리한다.

02

운영 목표

GOAL 01직접 운영하는 환경

기술을 설치 후 종료하는 실습이 아니라 지속적으로 사용하는 서비스에 적용한다.

GOAL 02외부 공개와 보안

공인 포트 노출을 최소화하고 Cloudflare Tunnel을 통해 서비스별 도메인을 연결한다.

GOAL 03반복 배포 자동화

정적 파일을 서버에 수동 복사하는 대신 Git Push를 기준으로 배포 흐름을 만든다.
